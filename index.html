Huawen Text Path Animator（华文文字路径动画编辑器）

Huawen Text Path Animator

概览 / Overview

本应用是一款完全离线的桌面软件，用于制作文字路径动画、字幕特效与视频导出。

This app is a fully offline desktop application for creating text path animations, subtitle effects, and video export.

All project files, images, audio, and videos are stored only on your local device and remain fully under your control. Uninstalling the app never uploads any data to the cloud.
